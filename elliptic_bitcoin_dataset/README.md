# Elliptic Bitcoin Dataset

This directory contains the Elliptic Bitcoin transaction graph dataset for anti-money laundering topological analysis.

## Tracked Files in GitHub
- `elliptic_txs_classes.csv` (3.15 MB) - Transaction illicit / licit labels
- `elliptic_txs_edgelist.csv` (4.26 MB) - Bitcoin graph transaction edgelist

## Large Feature File
- `elliptic_txs_features.csv` (657.73 MB) exceeds GitHub's 100MB upload limit and is hosted via the Elliptic Data benchmark repository on Kaggle.
